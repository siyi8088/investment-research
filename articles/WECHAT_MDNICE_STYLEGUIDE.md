### 二、 排版免死金牌核心速查表（Quick Reference）

为方便快速翻阅，第二层常驻防御规则中的核心对照速查如下：

| 排版场景 | ❌ 致命错误写法 (墨滴必崩) | ✅ 免死金牌写法 (100% 渲染成功) | 核心避坑机理 |
| :--- | :--- | :--- | :--- |
| **小标题冒号** | `* **门槛收益率 (Hurdle Rate)**:` | `* **门槛收益率 (Hurdle Rate)：** 正文` | 冒号移入加粗内，加粗后跟半角空格，消灭双标点夹击 |
| **百分比范围** | `**≥ 4.0% ~ 5.0%**` | `≥ **4.0% ~ 5.0%**` | 比较符号移到粗体外，粗体内只放纯数字与百分号 |
| **小于与HTML** | `**< 1.0%** 或为负数` | `< **1.0%** 或为负数` | `<` 移到粗体外，杜绝被误识别为 HTML 标签起始 |
| **约等于符号** | `＝ **10.95% ≈ 11.0%**；` | `＝ **10.95%** ≈ **11.0%** ；` | 约等于号外置，两端分别加粗，分号前显式留空格 |
| **粗体后句号** | `增速达到 **11.0%**。` | `增速达到 **11.0%** 。` | 粗体与全角句号之间留半角空格，防止定界符粘连 |
| **粗体后括号** | `新增 **2,050 亿美元**（其中...）` | `新增 **2,050 亿美元** （其中...）` | 粗体与全角括号之间留半角空格，防止定界符粘连 |
| **宏观货币单位** | `$7,450 亿美元`、`$40 亿` | `7,450 亿美元`、`40 亿美元` | 纯中文金融单位，彻底消灭裸露 `$` 跨段吞噬正文 |
| **股票点位代码块**| 裸露加粗 `**$171.55**` 或外层嵌套加粗 | `$171.55`（纯代码块） | 纯代码块包裹且外层绝不加粗，防止定界符冲突星号暴露 |
| **数学公式呈现** | 行内 `$IRR = (P/P_0)^{1/n}-1$` | 独占行 `$$ IRR = ... $$` | 墨滴自动转译为高清矢量 SVG，彻底禁用行内单 `$` |
| **表格数值单位** | 列头标了百万，单元格填 `16,290.0 M` | 表头统一定义，单元格填 `16,290.0` | 杜绝单元格附加 `M`、`B`、`$`，消灭单位冗余与解析风险 |
| **双公司对比** | 两行数据之间敲空行回车 | 同单元格内使用 `<br>`，不留空行 | 配合墨滴 CSS 消除行距，保证手机端紧凑不折叠溢出 |
