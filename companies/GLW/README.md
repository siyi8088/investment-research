   - GPF 汽油颗粒捕集器、催化蜂窝陶瓷载体与座舱曲面盖板玻璃。
5. **生命科学与新兴业务（Life Sciences，营收占比 ~5.5%）**：
   - 高通量生物反应器、细胞耗材与先进光学孵化。
