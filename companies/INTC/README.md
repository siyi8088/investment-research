## 4. 跟踪纪律与买点击球区

- **当前态度：** **严格观望，禁止抢反弹** ；
- **击球区间（Strike Zone）：** 
  - **一级建仓观察带：** `$50.00 ~ $55.00` （契合 SOTP 纯设计盘保守估值）；
  - **深度击球进攻带：** `$35.00 ~ $40.00` （逼近历史有形净资产与现金防御垫，非对称盈亏比显现）；
- **非价格定量红线（Kill Switches）：** 
  - 2026-12-15 前以色列 Fab 28 必须全面恢复满产；
  - 单季 Intel Foundry 营业亏损不得恶化超过 -23.0 亿美元；
  - Q4 实际 Non-GAAP 毛利率严禁跌破 35.0%；
  - 2027-03-31 前必须实现 18A Panther Lake 计算芯片商业化流片量产。
