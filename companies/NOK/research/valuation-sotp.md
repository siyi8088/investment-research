## 二、 关键财务假设与分部业绩预测 (FY2025A - FY2027E)

2026 年 1 月 1 日起，诺基亚正式确立以三大支柱为核心的全新架构：
1. **Network Infrastructure（网络基础设施，NI）**：涵盖 Optical Networks（Infinera 整合，800G/1.6T DCI 光互连）、IP Networks（自研 FP5 芯片路由器）及 Fixed Networks（FTTH 宽带光纤）；
2. **Mobile Infrastructure（移动基础设施，MI）**：涵盖 Radio Networks（AirScale 5G-A 无线基站、NVIDIA AI-RAN 联合方案）与 Core Software（云原生 5G SA 核心网、IMS 语音核心网）；
3. **Technology Standards（专利授权，Nokia Technologies）**：5G/6G 标准必要专利池（SEP）、汽车网联 IoT 与视音频多媒体编解码许可。

### 3.2 SOTP 目标每股价值推导

```text
┌────────────────────────────────────────────────────────────────────────┐
│ SOTP 股东权益价值公式推导：                                            │
│ Total Equity Value = Σ(Segment Operations EV) + Net Cash - Min. Int    │
└────────────────────────────────────────────────────────────────────────┘
```

1. **主营业务总企业价值 (Operations EV)**: **€47,494.1M ($52,718.5M)**
2. **(+) 加回集团账面综合净现金 (Add Net Cash)**: **+€2,776.0M (+$3,081.4M)**
3. **(=) 隐含股东权益总价值 (Implied Equity Value)**: **€50,270.1M ($55,799.9M)**
4. **(÷) 稀释普通股总股数 (Diluted Shares)**: **5,742.24M 股**
5. **(=) SOTP 隐含基准每股目标价**:
   $$\text{SOTP 芬兰母股目标价} = \frac{€50,270.1\text{M}}{5,742.24\text{M}} = \mathbf{€8.75}$$
   $$\text{SOTP 纽交所 ADR 目标价 (USD)} = €8.75 \times 1.11 = \mathbf{\$13.88}$$

## 四、 综合估值交叉验证与多场景矩阵

### 4.1 综合估值方法对齐

* **方法 1: 分部加总估值法 (SOTP)**: **$13.88** (权重 50%)
* **方法 2: 归一化市盈率倍数法 (Forward P/E)**:
  * 给予进入 AI 全光网高速成长期的诺基亚 **18.0x FY2027E 归一化 EPS ($0.40 USD)**（对比历史低谷 11-12x，完成向科技基础设施估值切换）:
    $$\text{P/E Target} = \$0.40 \times 18.0 = \mathbf{\$14.52} \text{ (权重 50\%)}$$
* **基准目标价 (Blended 12M Target Price)**:
  $$\text{Base Target Price} = 0.50 \times \$13.88 + 0.50 \times \$14.52 = \mathbf{\$14.20}$$
  * 相比当前股价 $10.68，具备 **+33.0%** 的确定性修复空间。

### 4.2 三情景收益分布与概率加权目标价

```text
        [熊市 Bear Case]             [当前股价]               [基准 Base Case]              [牛市 Bull Case]
            $8.80                     $10.68                     $14.20                        $18.00
   -----------|--------------------------|--------------------------|-----------------------------|-----> Price
           (-17.6%)                   (Current)                  (+33.0%)                       (+68.5%)
         [概率 20%]                                              [概率 60%]                    [概率 20%]
```

1. **牛市情景 (Bull Case - 概率 20%)**: **$18.00** (+68.5%)
   * **核心假设**: 北美及欧洲超大规模云厂商在 2026-2027 年全面开启 1.6T 光互连升级，Network Infrastructure 营收复合增速突破 15%，分部营业利润率升至 19%；AI-RAN 在日美韩运营商全面进入商用铺开；FY2027E EPS 达 **$0.48**，市场给予 **21.0x P/E** 估值。
2. **基准情景 (Base Case - 概率 60%)**: **$14.20** (+33.0%)
   * **核心假设**: AI/Cloud 订单稳步兑现，Optical Networks 保持 12-15% 稳态增长；Infinera 每年 €2 亿协同效应如期实现；移动基础设施微幅企稳；FY2027E EPS 达 **$0.40**，市场给予 **18.0x P/E**。
3. **熊市情景 (Bear Case - 概率 20%)**: **$8.80** (-17.6%)
   * **核心假设**: 云厂商 AI 资本开支出现阶段性消化停滞，DCI 订单推迟；宏观电信投资再次下滑；FY2027E EPS 停滞在 **$0.30**，市场维持 **13.0x P/E**。
4. **概率加权目标价 (Probability-Weighted Target)**:
   $$\text{Weighted Price} = (0.20 \times \$18.00) + (0.60 \times \$14.20) + (0.20 \times \$8.80) = \mathbf{\$13.88} \text{ (+30.0\%)}$$
5. **盈亏比评估 (Risk/Reward Asymmetry)**:
   $$\text{Risk/Reward Ratio} = \frac{\text{基准上涨空间 (\$14.20 - \$10.68)}}{\text{下行风险 (\$10.68 - \$8.80)}} = \frac{\$3.52}{\$1.88} = \mathbf{1.87 : 1}$$
   *(若按牛市上行空间 \$7.32 测算，盈亏比高达 **3.89 : 1**，呈现典型的非对称看涨配置价值)*。
