## 1. 一句话判断（Executive Summary）

> **波音公司（The Boeing Company）是不可替代的全球商用大飞机制造双寡头垄断者与美军核心国防装备支柱，正处于从“危机处置与现金失血”向“生产节拍稳定与正向自由现金流爆发”的历史性拐点**。
> 航空航天工业具备极端严苛的适航认证壁垒、万亿美元级研发沉没成本与超长研发周期，全球除波音与空中客车（Airbus）外，没有任何第三方能在未来数十年内撼动干线大型客机的双寡头格局。在经历了质量整顿、监管审查与 2024 年工会重组后，**新任 CEO Kelly Ortberg（原罗克韦尔柯林斯掌门人）重塑了以“安全、质量与工程纪律”为核心的工程师文化**。2026 年第二季度，波音交出了极具转折意义的成绩单：**单季交付 171 架商用飞机，GAAP 营业利润转正至 +$1.56 亿美元，自由现金流实现 +$6.31 亿美元正向回流，在手未交付订单创下 $7,150 亿美元历史新高（覆盖未来 8-9 年满产产能）**。波音兼具万亿订单高能见度与困境反转期权，当前估值处于长周期偏低区间，具备坚实的配置价值。

## 2. 核心投资亮点（Why Watch / Investment Highlights）

- **亮点 1：不可动摇的全球民用大飞机制造双寡头垄断地位（Duopoly Moat）**  
  全球民航机队正处于向新一代节能减碳客机（窄体机 737 MAX、宽体机 787 / 777X）全面更替的二十年超级周期。由于空客 A320neo / A350 产能同样已经排满至 2032 年以后，全球航空公司必须同时向波音与空客双向锁定机位。波音拥有全球无可替代的干线飞机总装交付能力与全球航材供应链话语权。
- **亮点 2：在手积压订单突破 $7,150 亿美元（>$715B），锁定未来 8-9 年全负荷产能**  
  截至 2026 年 Q2 末，波音全公司在手未交付订单（Backlog）跨越 **$7,150 亿美元** 历史天花板。其中商用飞机（BCA）积压订单超过 **6,200 架**，价值达 **$5,970 亿美元**；防务与太空（BDS）积压达 **$850 亿美元**；全球服务（BGS）积压达 **$330 亿美元**。这种跨越宏观经济周期的巨额订单储备，赋予了波音极高维度的中长期业绩确定性。
- **亮点 3：Kelly Ortberg 铁腕新政落地，重塑精益制造纪律与适航认证进程**  
  新任 CEO Kelly Ortberg 到任后将办公地点直接前置到西雅图制造一线，重组了质量安全审查流程，并推动与 Spirit AeroSystems 的供应链纵向一体化重组。Q2 财季标志着多项关键里程碑达成：
  1. **737 MAX**：正式过渡至 **47 架/月** 生产节拍，埃弗雷特（Everett）737 North Line 激活初始投产，目标 2027 年稳步爬坡至 52 架/月；
  2. **737-7 与 737-10**：适航审定试飞已全部顺利完成，预计 2026 年底获批、2027 年正式交付；
  3. **777X**：获 FAA 批准启动 TIA 4B 适航审定试飞，2027 年开启商业交付。
- **亮点 4：全球服务分部（BGS）充当极高利润率的防御性现金奶牛**  
  波音全球服务板块（BGS）依托全球超过 10,000 架现役波音客机底座，提供航材备件、改装维护、数字化飞行方案与军用机队保障。Q2 录得营收 **$53.4 亿美元**，营业利润高达 **$9.68 亿美元（营利率高达 18.1%）**。该板块年化产生近 **$40 亿美元** 的高纯度经营利润，为商用客机爬坡期提供了坚不可摧的现金流防线。
- **亮点 5：现金储备跃升至 $200 亿美元，资产负债表与自由现金流历史性扭亏转正**  
  通过 2024 年末发行的强制可转优先股与严苛的营运资本管理，截至 2026 年 Q2 末，波音账面拥有 **$200.2 亿美元** 的现金及短期投资储备，总有息负债持续压降至 $459.0 亿（净负债缩减至 $258.8 亿）。Q2 经营现金流达 **+$13.6 亿美元（同比暴增 501%）**，自由现金流正式转正为 **+$6.31 亿美元**，困境反转信号确立。

## 3. 商业模式与分部业务架构（Business Architecture & Revenue Streams）

### 3.1 公司是怎么赚钱的（Value Proposition & Monetization）

```text
┌────────────────────────────────────────────────────────────────────────┐
│                   THE BOEING COMPANY 全球航空航天与国防工业底座         │
└────────────────────────────────────────────────────────────────────────┘
                                    │
        ┌───────────────────────────┼───────────────────────────┐
        ▼                           ▼                           ▼
┌─────────────────────────┐ ┌─────────────────────────┐ ┌─────────────────────────┐
│ 1. 商用飞机 (BCA)       │ │ 2. 全球后市场服务 (BGS) │ │ 3. 防务与航天安全 (BDS) │
│ • 窄体客机 737 MAX      │ │ • 航材备件分销与物流   │ │ • F/A-18、F-15EX 战机   │
│ • 宽体客机 787 梦想飞机 │ │ • 客改货 (BCF) 与维修大修│ │ • P-8A 波塞冬、KC-46A   │
│ • 双通道旗舰 777X / 777 │ │ • 数字化机组与训练方案 │ │ • 卫星通信与导弹防御   │
│ • 交付 171 架/季，占48% │ │ • 营利率 18.1%，现金奶牛│ │ • 积压 $850 亿，出清中  │
└─────────────────────────┘ └─────────────────────────┘ └─────────────────────────┘
                                    │
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│ 4. 供应链整合纵向延伸：重组 Spirit AeroSystems 核心机身与机翼制造资产   │
│ 彻底消除机身外包制造缺陷，实现从原材料、机体结构件到整机总装的闭环把控 │
└────────────────────────────────────────────────────────────────────────┘
```

1. **商用飞机（BCA，营收占比 ~48%）**：
   - **交付阶段确认收入**：航空公司订机时支付前期预付款（PDP），飞机最终组装下线并经 FAA 签署试飞交付文件后，支付剩余尾款并确认全额营业收入。交付架次是决定 BCA 收入的最核心变量。
   - **单机利润率非线性释放**：随着 737 MAX 产率由 38 架/月过渡至 47 架/月并向 52 架/月迈进，每架飞机分摊的固定折旧与工厂开工成本大幅稀释，BCA 利润率将迅速由当前的 -2.7% 恢复至历史稳态的 **8%~12%**。
2. **全球服务（BGS，营收占比 ~22%）**：
   - **高毛利长尾后市场**：商用客机设计寿命长达 25-30 年，期间消耗的航材备件、发动机短舱更换、航电升级及结构大修（C/D 检）费用是初始购机款的数倍。BGS 享有极高的经常性收益与定价权。
3. **国防、太空与安全（BDS，营收占比 ~30%）**：
   - 为美国国防部（DoD）及盟国军队提供军用飞机与卫星系统。近年来受固定总价开发合同（VC-25B 新空军一号、KC-46A 加油机、T-7A 高级教练机、Starliner 飞船）通胀超支拖累，目前正处于减值计提尾声与交付收尾阶段。

## 6. 核心追踪变量与先导指标（Key Leading Indicators）

1. **先导指标 1：737 MAX 月度实际总装与出厂交付节拍（Delivery Cadence）**  
   密切追踪波音位于伦顿（Renton）与埃弗雷特（Everett）工厂的 737 月度交付量是否稳固在 **45-47 架/月**，并观察向 52 架/月迈进的时间表。
2. **先导指标 2：关键机型（737-7、737-10 与 777X）FAA 适航审定取证进度**  
   跟踪 737-7 与 737-10 在 2026 年底前能否如期获得 FAA 型号认证（Type Certification），以及 777X 的 TIA 4B 试飞数据。
3. **先导指标 3：防务板块（BDS）固定总价项目减值是否彻底出清**  
   关注 VC-25B（新空军一号）、KC-46A 等项目是否在下半年实现零额外大额亏损计提，验证管理层防务重组实效。
4. **先导指标 4：季度自由现金流（Free Cash Flow）可持续为正的斜率**  
   验证 Q2 达成的 +$6.3 亿正向现金流能否在 Q3-Q4 持续扩大，为后续去杠杆偿债提供底气。
