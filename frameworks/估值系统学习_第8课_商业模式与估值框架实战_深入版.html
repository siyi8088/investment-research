商业模式与估值框架实战

前 1–7 课解决“利润、现金流、倍数、EV、Growth + Margin、DCF、Reverse DCF”分别是什么。第 8 课解决更重要的问题：看到一家公司以后，到底先看什么？为什么用这个估值方法？什么时候这个方法会失真？

这一课最重要的一句话

不要先问“这家公司应该给多少 PE / PS”。先问“它到底靠什么经济机制赚钱？”
然后依次回答：收入来源 → 成本结构 → 利润率 → 增长所需再投资 → FCF → 风险与持续期 → 最合适的估值语言。

估值不是倍数竞赛，而是把商业模式翻译成未来现金流。倍数只是把复杂模型压缩成一个数字。

1. 为什么商业模式决定估值框架？

我们前面学过 P/E、P/FCF、EV/EBITDA、EV/Sales、P/S、DCF。现实里没有一家公司的所有倍数都同样有意义，原因是不同公司的利润与现金流，离“经济实质”的距离不同。

公司状态主要问题估值关注点
成熟 SaaS收入稳定、利润已兑现FCF / PE / DCF
高增长 SaaS利润尚未完全成熟Growth + Margin → EV/Sales → FCF
半导体周期与产品 MixNormalized PE / PFCF / DCF
重资产 AI InfraCapEx 巨大FCF / ROIC / DCF；谨慎 EV/EBITDA
工业/航空单年利润可能异常Normalized Earnings / FCF
平台型公司不同业务利润结构差异巨大SOTP + DCF
金融/保险资本本身就是业务原料P/B + ROE + Residual Income

2. 拿到一家公司，先画出“经营经济学地图”

层级问题指标估值含义
Revenue钱从哪里来？Growth / Price / Volume / Mix / RPO / Backlog决定未来现金流规模
Gross Margin每增加 1 元收入剩多少钱？GM / COGS / Mix决定利润天花板
Opex增长要花多少研发和销售费用？R&D / S&M / G&A决定经营杠杆
Operating Margin规模起来后能赚多少？EBIT / EBITDA Margin连接收入与经营利润
Working Capital增长会不会吃现金？DSO / DPO / Inventory / CCC影响 CFO / FCF
CapEx增长要投入多少固定资产？CapEx / Revenue决定 EBITDA→FCF 的距离
SBC现金流是否伴随稀释？SBC / diluted shares影响每股价值
Balance Sheet资本结构如何改变股东价值？Debt / Cash / Leases决定 EV ↔ Equity

模式第一观察指标主估值框架典型误区

4. 实战一：成熟 SaaS——Salesforce / Adobe

成熟 SaaS 的经济特征通常是：订阅收入、可预测性高、毛利率高、CapEx 低。当利润成熟后，FCF 是非常直接的价值代理变量。

Salesforce：增长逐步正常化，利润兑现增强

FY27 Q2 指标数据估值含义
Revenue$11.3B，+11%从高速增长进入成熟增长区间
cRPO$33.5B，+14%未来收入可见度高
GAAP Op Margin20.5%利润已经比较成熟
Non-GAAP Op Margin34.1%经营杠杆明显
FCF$1.1B，本季 +81%现金兑现强

来源：Salesforce FY27 Q2，2026-08-26。官方材料

估值升级：当 Revenue 已经稳定转化为 EBIT 和 FCF，就不应该继续只用 PS。P/FCF、PE、DCF 的信息密度更高。

5. 实战二：高增长 SaaS——Snowflake

FY27 Q1 指标数据应该怎么读
Revenue$1.39B，+33%仍是高增长
Product Revenue$1.33B，+34%核心业务增长更快
NRR126%老客户本身仍在扩容
RPO$9.21B，+38%未来收入可见度较强
FY27 Product Revenue Guide$5.84B，+31%市场交易的是未来，而非当前
FY27 Non-GAAP Op Margin13.5%同时证明“增长→利润”
FY27 Adjusted FCF Margin23%FCF 已成为关键指标

来源：Snowflake FY27 Q1 / FY27 guidance。官方材料

EV ≈ Revenue × EV/Sales

但深层经济链是：
Revenue × Gross Margin × Operating Leverage × FCF Conversion → Long-term FCF

所以 Snowflake 型公司适合走：

EV/Sales → Growth + Margin → FCF → Reverse DCF

不要问“30% 增长 × 多少倍 PS？”应该问：30% 增长能持续多久？成熟 FCF Margin 最终是多少？SBC 后的每股现金流是多少？

6. 实战三：半导体——NVIDIA / Broadcom

NVIDIA：极高 Growth + 极高 Margin 的组合

FY27 Q2数据估值关注点
Revenue$96.2B，+106%当前仍是超高速增长
Data Center$89.0B，+117%AI 是主要增长引擎
Gross Margin约 75%经济质量高，但要观察成本与 Mix
Operating Margin约 66%经营杠杆巨大
FY28 preliminary revenue growth约 +70%市场远期锚点极高

来源：NVIDIA FY27 Q2 10-Q 与 2026-08-26 earnings call。10-Q / 电话会

这里 Reverse Valuation 比单纯 PE 更重要：当前价格隐含了多少 Revenue、Margin、duration？比如毛利率从 75% 向 72%–73% 走，仍然能不能支持当前估值？

Broadcom：P/FCF 是非常强的第二确认器

FY26 Q3数据观察
Revenue$29.6B，+86%增长很强
GAAP Operating Income$16.0B利润率极高
CFO$14.2B现金创造强
FCF$13.7B约占收入 46%
Q4 Revenue Guide约 $34.8B仍处高增长

来源：Broadcom FY26 Q3，2026-09-02。官方材料

半导体的关键难点不是“PE 多少”，而是 Normalized Earnings。当前季度利润可能来自极佳产品 Mix / 周期；所以要估“正常利润”，再谈合理倍数。

7. 实战四：AI Infrastructure——为什么 EBITDA 可能骗人？

数据中心、GPU 云、算力租赁等业务的共同特征是：资产寿命有限，但为了扩大收入又必须持续购买 GPU、服务器、网络设备、电力与机房设施。

EBITDA = EBIT + D&A

但 FCF ≈ EBITDA - Cash Taxes - CapEx - ΔNWC
因此：“EV/EBITDA 很低”不自动等于“很便宜”。如果企业必须持续高 CapEx 才能维持收入，EBITDA 会高估可分配现金。

这类公司应该增加三组指标

指标你真正问的问题
CapEx / Revenue每 1 元收入需要多少新增资本？
ROIC投入资本到底赚多少？
Utilization / Contract Duration资产有没有充分使用，合同是否覆盖资产寿命？
Debt / Maturity增长放缓以后现金流能否支撑债务？

8. 实战五：工业与航空——必须做“正常化估值”

Boeing：先算正常化 FCF，而不是直接看当期 PE

2026 Q2数据为什么重要
Revenue$24.6B，+8%业务修复
Commercial deliveries171 架生产/交付决定收入
Operating income$156M当前利润率仍低
FCF$0.6B改善但不能直接视为成熟水平
Backlog$715B长期需求可见度高

来源：Boeing 2026-07-28 Q2。官方材料

Normalized FCF = Normalized Revenue × Normalized FCF Margin

再考虑：产能爬坡 + 供应链 + 库存 + 预付款 + 质量/认证成本

核心问题：现在的利润是“谷底利润”还是“正常利润”？恢复到正常状态需要几年？

GE Aerospace：航空航天也必须看“业务结构”

GE Aerospace 2026 Q2 总收入 $13.3B，同比增长 21%；经营利润率约 21.7%；FCF $3.0B，同比增长 43%。公司商用发动机服务业务增长明显，服务收入与设备业务的经济结构不同。官方材料

同属航空航天，估值逻辑也可能不同：Boeing 更像制造/生产恢复；GE Aerospace 的高利润服务业务让它更接近“高质量工业+长期服务现金流”。

9. 实战六：Amazon——为什么 SOTP 比单一 PE 更合理？

Amazon 把低毛利零售、高利润 AWS、广告以及巨额基础设施投入放进一个损益表。单一 PE 会把不同经济学混在一起。

North America$116.2B$9.1B
International$42.2B$1.7B
AWS$42.2B$16.6B
Consolidated$200.6B$27.5B

来源：Amazon 2026-07-30 Q2。官方材料

更值得注意：截至 2026-06-30 的 TTM，CFO $161.4B，但 FCF 为 -$7.6B，主要与 Property & Equipment 购买增加有关。官方材料

Amazon Equity Value ≈ Retail Value + AWS Value + Advertising Value + Other - Net Debt / Claims

10. 金融/保险——为什么 P/B + ROE 是另一套语言？

保险与软件的重要区别是：资本本身就是业务原料。保险公司需要资本承保风险、配置资产并满足监管要求，因此 Book Value 具有经济含义。

指标含义估值作用
Book Value净资产/资本基础P/B 的分母
ROE净利润 / 平均净资产资本赚钱能力
Combined Ratio赔付+费用 / 保费承保盈利能力
Investment Income保险资金投资收益重要利润来源
P/B 的经济逻辑可以粗略理解为：

资本 × 长期 ROE → 可持续利润 → 股东愿意为这套资本机器支付多少溢价

所以金融估值的语言更接近：P/B ↔ ROE ↔ Growth ↔ Risk。

13. 四个实战模板

Snowflake

① Product Growth → ② NRR/RPO → ③ GM → ④ Operating Margin → ⑤ FCF Margin → ⑥ EV/Sales → ⑦ Reverse DCF。

核心问题：30%左右增长能持续多久？成熟 FCF Margin 最终是多少？

NVIDIA

① Data Center Growth → ② 产品周期 → ③ GM → ④ Operating Leverage → ⑤ FCF → ⑥ Forward PE/PFCF → ⑦ Reverse DCF。

核心问题：AI CapEx、竞争与产品迭代能否维持高 Growth + 高 Margin？

Boeing

① Deliveries → ② Backlog → ③ Production Rate → ④ Normalized Margin → ⑤ Normalized FCF → ⑥ DCF。

核心问题：当前是不是谷底？恢复后的正常 FCF 有多少？

Amazon

① Segment Revenue → ② Segment Margin → ③ CapEx → ④ Consolidated FCF → ⑤ SOTP → ⑥ DCF。

核心问题：AWS、广告、零售各自值多少？增长需要多少资本？

14. 最终决策树：以后你看到任何公司都这样做

问题判断优先框架
收入是否稳定可预测？是P/FCF、PE、DCF
利润是否成熟？否EV/Sales + Growth + Margin + FCF
CapEx 是否很重？是FCF / DCF / ROIC；谨慎 EBITDA
周期性是否很强？是Normalized Earnings / FCF
业务结构是否高度异质？是SOTP
资本本身是否是生产要素？是P/B + ROE / Residual Income

你的公司研究模板

  1. 一句话商业模式：给谁卖什么，怎么收费？
  2. 收入拆解：Volume / Price / Mix / New Product / M&A / FX。
  3. Margin：Gross Margin → Operating Margin → FCF Margin。
  4. 增长质量：NRR / RPO / Backlog / Market Share / Customer Concentration。
  5. 资本强度：CapEx / Revenue、D&A、Working Capital。
  6. 生命周期：早期 / 高增长 / 成熟 / 周期谷底 / 周期高峰？
  7. 估值：主方法 1 个，交叉验证方法 1–2 个。
  8. Reverse：当前价格要求什么增长、Margin、FCF？
  9. 失效条件：哪个经营变量一旦恶化，整个估值逻辑就需要重算？

15. 最容易犯的 10 个错误

#错误本质问题
1PE 低就认为便宜可能正处周期高峰
2PS 低就认为便宜低毛利收入不等价于高质量收入
3EBITDA 当 FCF忽略 CapEx / 税 / NWC
4只看增长没看 Margin 与现金兑现
5只看公司指引没看市场已经预期什么
6当前 Margin 永久化Mix / 周期会变化
7忽略 SBC忽略经济稀释
8忽略稀释股数企业价值增长不等于每股价值增长
9忘记 EV↔EquityDebt / Cash 会改变股东价值
10模型精确到小数点后两位真正不确定的是 Growth / Margin / Duration
把第 1–8 课压缩成一条链：
商业模式 → Revenue Drivers → Gross Margin → Operating Leverage → FCF → Capital Intensity → Lifecycle → Valuation Method → Reverse Valuation
