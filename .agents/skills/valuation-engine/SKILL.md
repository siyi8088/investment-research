# 估值与预期投资学引擎（Valuation & Expectations Engine）

本规程指导分析师跳出传统正向预测的“自嗨陷阱”，首先通过**反向 DCF** 解码二级市场当前价格中隐含的履职军令状，再结合垂直行业的专属经济学模型、正向三情景推演与敏感性网格，建立立体交叉的多模型公允价值定锚体系，沉淀为 `companies/<TICKER>/` 中的核心估值底稿。

---

## 核心总则：投研超集第一阶段必须交付的 3 大估值底表

在进行个股估值推演时，`valuation-engine` 必须负责直接交付以下 3 张标准底表：
1. **【底表 3：反向 DCF 逆向求解底稿】**（现价隐含 10 年 FCF 年化增速、第 10 年终局门槛、莫布森 2×2 矩阵判定）；
2. **【底表 4：垂直商业物种专属估值底稿】**（SOTP 分部加总 / 周期中枢正常化 / SaaS 稳态 FCF 折现，显性列示四大基石假设）；
3. **【底表 5：正向三情景推演、双变量压测网格与多模型合成目标价】**（Bear 20% / Base 60% / Bull 20%、EPS×PE 36 格网格、WACC×g 30 格网格、多模型交叉验证综合公允目标价与悲观防御底座）。

## 一、 墨滴 (mdnice) 排版四大免死铁律

所有交付文本必须严格执行以下排版铁律：
- **宏观体量一律采用标准中文单位**：统一写作纯中文金融单位（如 `7,450 亿美元`、`10.20 亿美元`、`40 亿美元`），严禁 `$xx 亿美元` 混杂。
- **每股股价与点位一律使用纯行内代码块包裹，外层绝对严禁加粗**：统一写作纯行内代码块（如 `` `$171.55` ``、`` `$227.00` ``、`` `$136.00` ``），严禁写成 `**$171.55**` 或 `**`$171.55`**`。
- **加粗防粘连空距铁律（Pangu Spacing）**：闭合星号遇中文标点显式留半角空格（如 `**8.5%** （`）；算术与比较符号一律外置并留半角空格（如 `+ **32.3%** ，`、`- **20.7%** ）`、`≥ **4.0%**`）。
- **表格紧凑化**：表头显式声明单位，单元格纯数值不带散落的 `$`。

## 二、 核心模块一：反向 DCF 逆向求解规程（破除分析师自嗨）

### 1. 为什么必须先做反向 DCF？
传统正向 DCF（自己填增速、自己算目标价）极易陷入确认偏误。反向 DCF 颠覆逻辑：**把二级市场价格当成客观事实，倒推市场给管理层开出的“履职军令状”**。

### 2. 自动化执行工具
调用本技能内置的专用解算脚本：
```bash
python3 .agents/skills/valuation-engine/scripts/reverse_dcf.py \
  --ticker <TICKER> \
  --price <CURRENT_PRICE> \
  --shares <DILUTED_SHARES_M> \
  --net_debt <NET_DEBT_M> \
  --wacc <WACC> \
  --g <PERPETUAL_G> \
  --base_fcf <NORMALIZED_BASE_FCF_M> \
  --hist_cagr <HIST_5YR_CAGR> \
  --mgmt_guidance <MGMT_GUIDANCE>
```

### 3. 莫布森 2×2 预期差决战矩阵判定准则

| 市场隐含预期要求 | 真实产业爆发力强劲 (High Reality) | 真实产业平庸/承压 (Low Reality) |
| :--- | :--- | :--- |
| **极度狂热 / 高要求<br>(隐含 FCF 增速 ＞ 20%)** | **【象限 A：定价完美 (Priced for Perfection)】**<br>哪怕创造奇迹也已被全额预支，容错率极低，轻微放缓即遭遇估值血洗 | **【象限 D：双重绞杀 (Disaster Zone)】**<br>高估值泡沫叠加基本面暴雷，戴维斯双杀本金毁灭 |
| **极度保守 / 低要求<br>(隐含 FCF 增速 ＜ 5%)** | **【象限 B：深度折价 / 黄金坑 (Mispriced Alpha)】**<br>市场过度悲观，预期差极其有利，戴维斯双击的暴利源泉 | **【象限 C：低估值陷阱 (Value Trap)】**<br>看似便宜但缺乏护城河，基本面持续失血 |

## 三、 核心模块二：垂直商业物种专属估值方法库

严禁用同一种估值倍数套用所有企业，必须根据商业底层物种匹配专属模型，且**必须显性交代四大基石假设**（提产/交付执行节奏、估值倍数同业对齐依据、股权稀释与再融资假设、管理层胜任力）：

### 1. 多元化航母与平台企业（SOTP Playbook）
* **分部企业价值桥测算四步法**：
  1. **分部 Core EBIT / EBITDA 优先**：基于 10-Q/10-K 分部披露的稳态营业利润测算分部企业价值（Segment EV）；
  2. **纯粹龙头对标**：每个分部严格锚定细分赛道的 Pure-play 龙头，显性计入监管/治理折价（如 FAA 折价 10%）；
  3. **集团层面扣除净负债**：`股东权益内在价值 ＝ ∑(分部 EV) − 集团稳态净负债`；
  4. **每股公允价值输出**：除以完全稀释股本。

### 2. 半导体与硬科技（Semiconductor & Hardware Playbook）
* **核心物理机制**：强周期性（硅周期）、高沉没资本开支（Fab CapEx）与制程良率爬坡。
* **中枢正常化估值法（Through-the-Cycle Normalization）**：
  - 调取过去 7~10 年完整周期的**历史平均毛利率与平均营业利润率**；
  - 结合当前产能与合理开工率，测算出穿越周期的**“中枢正常化 EPS / FCF”**；
  - 显性计入地缘政治与供应链脱钩折价（如 20%~25%）。

### 3. SaaS 与轻资产平台（Subscription Playbook）
* **核心体检指标**：Rule of 40（YoY 增速 ＋ FCF Margin $\ge 40\%$）、净留存率（NRR $\ge 110\%$）、CAC 回收期（$\le 14$ 个月）。
* **估值切换准则**：营收增速 $> 30\%$ 采用 EV/Sales；增速滑落至 $20\%$ 以下强制切换为 EV/FCF 或 P/FCF。

### 4. 悲观防御底座确立准则（风控短板论）
衡量下行风险时，直接对比三独立模型测算的悲观下限：
* 三情景 Bear Case 底（如 `$136.00`）
* DCF 极限高息压测底（如 `$136.80`）
* SOTP 保守资产底（如 `$143.00`）
**直接锚定三者中最严苛的底线作为防御底座**（如 `$136.00`），严禁使用平均法熨平下行风险。
