# 估值与预期投资学引擎（Valuation & Expectations Engine）

本规程指导分析师跳出传统正向预测的“自嗨陷阱”，首先通过**反向 DCF** 解码二级市场当前价格中隐含的履职预期，再结合垂直行业的专属经济学模型、正向多情景推演与敏感性网格，建立立体交叉的多模型公允价值定锚体系，沉淀为 `companies/<TICKER>/` 中的核心估值底稿。

---

## 核心总则：投研超集第一阶段必须交付的 3 大估值底表

在进行个股估值推演时，`valuation-engine` 必须负责直接交付以下 3 张标准底表：
1. **【底表 3：反向 DCF 逆向求解与基准概率（Base Rate）】**（现价隐含 10 年 FCF 年化增速、第 10 年终局门槛、莫布森 2×2 预期投资矩阵判定、商业史基准大数审计）；
2. **【底表 4：分类加总估值模型（SOTP）与资产错配定价】**（SOTP 分部加总 / 周期中枢正常化 / 稳态折现模型，显性列示支撑测算的基石假设）；
3. **【底表 5：三情景目标价、双向敏感性矩阵与底线价值筑底】**（Bear 20% / Base 60% / Bull 20%、盈利×乘数网格、贴现率×增长率网格、多模型交叉验证综合公允目标价与防御底线）。

## 一、 核心模块一：反向 DCF 逆向求解规程（破除分析师自嗨）

### 1. 为什么必须先做反向 DCF？
传统正向 DCF（自己填增速、自己算目标价）极易陷入确认偏误。反向 DCF 颠覆逻辑：**把二级市场价格当成客观事实，倒推市场给管理层开出的“隐式考卷”**。

### 2. 自动化执行工具
调用本技能内置的专用解算脚本：
```bash
python3 .agents/skills/valuation-engine/scripts/reverse_dcf.py \
  --ticker <TICKER> \
  --price <CURRENT_PRICE> \
  --shares <DILUTED_SHARES_M> \
  --net_debt <NET_DEBT_M> \
  --wacc <WACC> \
  --g <PERPETUAL_G> \
  --base_fcf <NORMALIZED_BASE_FCF_M> \
  --hist_cagr <HIST_5YR_CAGR> \
  --mgmt_guidance <MGMT_GUIDANCE>
```

### 3. 莫布森 2×2 预期投资矩阵判定准则

| 市场隐含预期要求 | 真实产业爆发力强劲 (High Reality) | 真实产业平庸/承压 (Low Reality) |
| :--- | :--- | :--- |
| **极度狂热 / 高要求<br>(隐含 FCF 增速 ＞ 20%)** | **【象限 A：定价完美 (Priced for Perfection)】**<br>哪怕创造奇迹也已被全额预支，容错率极低，轻微放缓即遭遇估值踩踏 | **【象限 D：双重绞杀 (Disaster Zone)】**<br>高估值泡沫叠加基本面暴雷，戴维斯双杀本金毁灭 |
| **极度保守 / 低要求<br>(隐含 FCF 增速 ＜ 5%)** | **【象限 B：深度折价 / 黄金坑 (Mispriced Alpha)】**<br>市场过度悲观，预期差极其有利，戴维斯双击的潜在源泉 | **【象限 C：低估值陷阱 (Value Trap)】**<br>看似便宜但缺乏护城河，基本面持续失血 |

## 二、 核心模块二：垂直商业物种专属估值方法库

严禁用同一种估值倍数套用所有企业，必须根据商业底层物种匹配专属模型，且**必须显性交代支撑模型成立的基石假设**（如执行节奏、对标乘数依据、股本变动假设、资本分配纪律等，不设固定数量限制）：

### 1. 分部加总估值模型（SOTP Playbook）
* **分部企业价值测算四步法**：
  1. **分部 Core EBIT / EBITDA 优先**：基于分部披露的稳态利润测算分部企业价值（Segment EV）；
  2. **细分对标与折溢价**：每个分部严格锚定细分赛道的纯粹可比同行，显性说明折价或溢价理由；
  3. **经济利差减记与产业链摩擦折让**：
     - 凡属于持续经营失血且增量投资资本回报率（RONIC）低于 WACC 的重资产业务，严禁按账面净资产直接加总，须进行经济利差减记或将预期失血贴现扣除；
     - 核心工序外包、毛利率被上下游严重挤压的业务，乘数须计入议价权受损折价；
  4. **集团层面扣除净负债与少数股东权益**：`股东权益内在价值 ＝ ∑(分部 EV) − 集团稳态净负债 − 外部少数股东权益`；除以完全稀释股本得出每股价值。

### 2. 周期中枢正常化估值模型（Through-the-Cycle Normalization）
* 调取完整周期的历史平均毛利率与平均营业利润率；
* 结合当前产能与合理开工率，测算出穿越周期的“中枢正常化 EPS / FCF”，避免在周期顶峰高估或周期低谷低估。

### 3. 稳态现金流贴现模型（Normalized DCF）
* 针对轻资产高复利或商业模式处于稳定期的资产，基于穿越周期的稳态自由现金流进行标准折现。

### 4. 悲观防御底座确立准则（风控短板论与现实硬核校验）
衡量下行风险时，直接对比三独立模型测算的悲观下限：
* 三情景 Bear Case 底
* DCF 极限偏紧折现底
* SOTP 保守资产底
**直接锚定三者中最严苛的底线作为防御底座**，严禁使用平均法熨平下行风险。

> **★ 买方第一性原理：防御底座的现实硬核核验（Triangulated Defense Floor）**：  
> 纸面模型推导出的悲观防御底座，必须通过两道客观现实铁底核验：  
> 1. **会计硬事实**：GAAP 官方有形每股净资产（Tangible Book Value per share, TBVPS）与高流动性现金储备；  
> 2. **市场硬事实**：标的在过去周期中的真实最低成交价格区间；  
> 3. **买方禁令**：分析师严禁将一个包含乐观盈利倍数假定的纸面模型结果宣称为绝对不可击穿的物理铁底，必须在底表中显性提示在极端不利情景下回踩历史极值低点的下行风险，杜绝制造虚假的非对称盈亏比。
