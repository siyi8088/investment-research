# 估值与预期投资学引擎（Valuation & Expectations Engine）

本规程指导分析师跳出传统正向预测的“自嗨陷阱”，首先通过**反向 DCF** 解码二级市场当前价格中隐含的军令状，再结合垂直行业的专属经济学模型，建立立体交叉的三情景财务估值底表。

---

## 一、 核心工作流结构

```text
┌────────────────────────────────────────────────────────┐
│ 第一步：反向 DCF 预期拆解 (Expectations Investing)      │
│ • 用市价逆向求解：市场要求未来 10 年 FCF 年化增速是多少？│
│ • 对照历史 5 年增速与管理层指引，测算“预期剪刀差”      │
│ • 定位莫布森 2×2 决战矩阵（是否 Priced for Perfection）│
└───────────────────────────┬────────────────────────────┘
                            │ 明确市场底牌与定价象限
                            ▼
┌────────────────────────────────────────────────────────┐
│ 第二步：垂直商业物种估值适配 (Industry Archetypes)     │
│ • SaaS / 订阅制：Rule of 40、NRR、PS 转 FCF 估值       │
│ • 半导体 / 硬科技：硅周期拐点、良率爬坡、中枢正常化    │
│ • 多元化航母：SOTP 分部企业价值桥、控股折价评估       │
└───────────────────────────┬────────────────────────────┘
                            │ 适配产业第一性原理模型
                            ▼
┌────────────────────────────────────────────────────────┐
│ 第三步：正向三情景预测与非对称盈亏比 (3-Scenario DCF) │
│ • 建立 Bear (25%) / Base (50%) / Bull (25%) 预测底表    │
│ • 计算概率加权公允价值与期望盈亏比 (Risk/Reward)       │
└────────────────────────────────────────────────────────┘
```

## 二、 核心模块一：反向 DCF 逆向求解规程（破除分析师自嗨）

### 1. 为什么必须先做反向 DCF？
传统正向 DCF（自己填增速、自己算目标价）极易陷入确认偏误。反向 DCF 颠覆逻辑：**把二级市场价格当成客观事实，倒推市场给管理层开出的“履职军令状”**。

### 2. 自动化执行工具
调用本技能内置的专用解算脚本：
```bash
python3 .agents/skills/valuation-engine/scripts/reverse_dcf.py \
  --ticker <TICKER> \
  --price <CURRENT_PRICE> \
  --shares <DILUTED_SHARES_M> \
  --net_debt <NET_DEBT_M> \
  --wacc <WACC> \
  --g <PERPETUAL_G> \
  --base_fcf <NORMALIZED_BASE_FCF_M> \
  --hist_cagr <HIST_5YR_CAGR> \
  --mgmt_guidance <MGMT_GUIDANCE>
```

### 3. 莫布森 2×2 预期差决战矩阵判定准则

| 市场隐含预期要求 | 真实产业爆发力强劲 (High Reality) | 真实产业平庸/承压 (Low Reality) |
| :--- | :--- | :--- |
| **极度狂热 / 高要求<br>(隐含 FCF 增速 ＞ 20%)** | **【象限 A：定价完美 (Priced for Perfection)】**<br>哪怕创造奇迹也已被全额预支，容错率极低，轻微放缓即遭遇估值血洗（如康宁高位、英伟达极端狂热期） | **【象限 D：双重绞杀 (Disaster Zone)】**<br>高估值泡沫叠加基本面暴雷，戴维斯双杀本金毁灭 |
| **极度保守 / 低要求<br>(隐含 FCF 增速 ＜ 5%)** | **【象限 B：深度折价 / 黄金坑 (Mispriced Alpha)】**<br>市场过度悲观，预期差极其有利，戴维斯双击的暴利源泉 | **【象限 C：低估值陷阱 (Value Trap)】**<br>看似便宜但缺乏护城河，基本面持续失血 |

## 三、 核心模块二：垂直商业物种专属估值方法库

严禁用同一种估值倍数套用所有企业，必须根据商业底层物种匹配专属模型：

### 1. SaaS 与订阅经济学（Subscription Playbook）
* **核心体检指标**：
  * **Rule of 40（40法则）**：`营收 YoY 增速 (%) ＋ 自由现金流率 FCF Margin (%) ≥ 40%`；
  * **净留存率 (NRR)**：`NRR ≥ 110%`（优秀 SaaS 达 120%+，体现负流失与老客扩张杠杆）；
  * **CAC 投资回收期**：获客成本回收周期 `≤ 14 个月`。
* **估值切换准则**：
  * 当营收增速 $> 30\%$ 且仍处于大举获客期时，采用 **EV / Sales** 并根据 Rule of 40 分值给予溢价/折价；
  * 当增速滑落至 $20\%$ 以下时，市场必然抛弃 PS 逻辑，**强制切换为 EV / FCF 或 P/FCF 估值**。

### 2. 半导体与硬科技（Semiconductor & Hardware Playbook）
* **核心物理机制**：强周期性（硅周期）、高沉没资本开支（Fab CapEx）与制程良率爬坡。
* **估值防坑准则**：
  * **警惕周期高点 PE 陷阱**：在行业缺芯、毛利率冲至 60% 历史顶峰时，哪怕 PE 只有 8 倍也不可轻信，因为分母利润即将腰斩；
  * **中枢正常化估值法（Through-the-Cycle Normalization）**：
    - 调取过去 7~10 年完整周期的**历史平均毛利率与平均营业利润率**；
    - 结合当前产能与合理开工率，测算出穿越周期的**“中枢正常化 EPS / FCF”**；
    - 在周期底部（亏损或极低毛利时）用中枢利润给予中枢倍数进行左侧布局。

### 3. 多元化航母与平台企业（SOTP Playbook）
* **分部企业价值桥测算四步法**：
  1. **分部 EBITDA / 营业利润优先**：直接基于 10-Q/10-K 分部披露的 Segment Operating Income / EBITDA 测算分部企业价值（Segment EV）；
  2. **纯粹龙头对标**：每个分部严格锚定细分赛道的 Pure-play 龙头（如 AWS 对标云原生 SaaS/数据中台龙头，零售对标电商与物流仓储）；
  3. **集团层面扣除净负债**：
     `总股权内在价值 ＝ ∑(分部 EV) − 集团综合净负债 − 少数股东权益`
  4. **控股折价（Conglomerate Discount）**：通常给予多元化业务 10%~15% 的综合折价；若管理层宣布独立拆分上市或重大资产剥离，折价消除即为估值解锁催化剂。
