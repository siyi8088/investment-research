# 投研总览与信披数据基石协议（Investment Research Master Protocol）

本规范作为整个投资研究体系的总控协议（Master Orchestrator），统领所有个股研究的数据信披真伪、历史回溯深度、报表勾稽与下游专项技能（财报排雷、估值引擎、投资备忘录）的调用编排。

---

## 一、 核心铁律：零幻觉与数据基准线（Zero-Hallucination Policy）

1. **事实数据（Fact）与预测数据（Estimate）必须严格区隔**：
   - 已发生财务数据（历史营收、净利润、毛利率、EPS、现金流等）必须来自官方第一手信披，严禁使用大模型记忆盲估；
   - 预测数据必须明确标注为 `E`（如 `FY27E`）或 `[预估]`，并附带明确的驱动假设。
2. **实时市价基准线前置核准**：
   - 任何估值与分析前，必须核准标的**最新真实收盘股价（Current Market Price）**、稀释总股本（Diluted Shares）及当前总市值（Market Cap），严禁使用过时记忆。
3. **数据缺失时的规范处理**：
   - 若某项特定数据无法通过官方信披核实，必须在表格中留空并注明 `[待官方披露/待核实]`，严禁私自编造数字填补空白。

---

## 二、 美股信披“双轨制”与第一手信源穿透（Dual-Track SEC & Transcript Verification）

投资研究必须掌握美股上市公司信披的“双轨制”特征，**单一依靠 SEC 报表或单一依靠新闻报道均会造成重大误判**：

```text
┌──────────────────────────────────────────────────────────┐     ┌──────────────────────────────────────────────────────────┐
│              1. SEC 官方法定归档轨 (Form 8-K / 10-Q)      │     │            2. IR 电话会实录轨 (Earnings Call Transcript) │
├──────────────────────────────────────────────────────────┤     ├──────────────────────────────────────────────────────────┤
│ • 核心定位：历史客观硬事实（Ground Truth of the Past）   │     │ • 核心定位：前瞻指引与预期差（Alpha & Forward Guidance） │
│ • 特点：经严苛法律与审计审核，高度保守，只给紧邻下季指引 │     │ • 特点：在口头“安全港（Safe Harbor）”免责保护下进行      │
│ • 必查内容：分部业务营收底表、Non-GAAP 对账、现金流量表、│     │ • 必查内容：管理层口头定调、超预期跨期展望、供需瓶颈、  │
│   资产负债表与采购承诺（Commitments）                    │     │   以及华尔街分析师 Q&A 连环盘问出的真实底牌              │
└──────────────────────────────────────────────────────────┘     └──────────────────────────────────────────────────────────┘
```

1. **为什么必须双轨互验？**
   - SEC 8-K/10-Q 书面文件只敢保守陈述紧邻季度预测；而管理层对远期年度展望（如算力供需瓶颈、重大客户合作、先进制程良率）往往在**电话会口头陈述与分析师 Q&A** 中直接披露。
2. **IR 平台与实录直达路径**：
   - 美股核心科技与消费大厂多采用 **Q4 Inc.**（`s2xx.q4cdn.com/<Client_ID>/...`）托管官方 IR，官方文字实录多由 **FactSet CallStreet** 制作；
   - 权威获取路径：官方 IR 门户页面（`investor.<company>.com`）直达 Transcript，或 SEC EDGAR 调取 8-K 附件。
3. **财报复盘文档强制性规范**：
   - 必须包含**两大电话会核心模块**：
     - ① **管理层开场口头定调（CEO/CFO Prepared Remarks & Strategic Tone）**：定性基调、跨期口头指引与供应链现状；
     - ② **分析师尖锐 Q&A 核心交锋（Analyst Q&A Highlights）**：结构化还原 2~3 个最具争议性的交锋点（如交付节奏、良率、客户意向、毛利承压）。

## 三、 历史财报回溯深度与年报季报勾稽规程（Historical & TTM Reconciliation）

为解决“只看年报太滞后、只看季报有季节性与口径失真”的痛点，研究统一执行以下标准：

### 1. 历史基准线深度（Historical Horizon）
* **常规标的**：必须拉取过去 **3~5 年完整的 Form 10-K** 历史数据，确立营收增速、毛利率波动区间、CFO/NI 转化率的历史中枢；
* **强周期行业（半导体、航运、能源、重资产材料）**：必须回溯一个**完整周期（7~10 年）**，测算穿越周期的“中枢正常化”盈利能力。

### 2. 年报与季报的无缝勾稽（SEC Reconciliation Mechanics）
* **无 Q4 10-Q 机制**：美股前三季度分别披露 Form 10-Q，第四季度不发 10-Q，直接披露经全面审计的 **Form 10-K（年报）**。
  - 单季 Q4 测算公式：`Q4 单季 = 10-K 全年数据 − Q3 10-Q 的前 9 个月累计 (9-Month YTD)`。
* **时效性与去季节性：滚动 TTM（Trailing Twelve Months）**：
  - 损益与现金流指标采用最新 TTM 滚动数据：
    `TTM 当前数据 ＝ 最新 10-Q 累计 (YTD) ＋ 上年 10-K 全年 − 上年同期 10-Q 累计`；
  - TTM 既吸纳了最新单季的边际变化，又跨越了连续四个季度，彻底烫平了季节性波动。
* **资产负债表存量规则**：
  - 现金储备、有息负债、稀释股本等**时点存量指标（Balance Sheet）**，**一律直接采用最新单季 10-Q 期末值**，不进行跨期平均。

## 四、 图表时间颗粒度规范指南（Chart Granularity Protocol）

图表数据点的划分必须严格匹配金融指标的物理实质，避免一律按季度划分带来的剧烈抖动或噪音：

| 适用时间颗粒度 | 适用金融场景 | 典型图表案例 | 为什么这么选？ |
| :--- | :--- | :--- | :--- |
| **单季数据 (Quarterly)** | 高频边际拐点、经营体温 | 分部业务单季营收环比、毛利率季度漂移、实际业绩 vs 指引 (Beat/Miss) | 捕捉业务最新边际变化与放缓预警 |
| **滚动 TTM (Rolling 4Q)** | 平滑季节性波动的比率 | CFO ÷ 净利润转化率、净营业周期 CCC 天数、历史 P/E Band | 剔除单季税收结算与季节性突变，看真实造血中枢 |
| **完整年度 (Annual FY)** | 战略定力、资本分配、远期估值 | 5 年资本分配堆叠图（CapEx/回购/分红）、DCF 未来 5~10 年 FCF 推演底表 | 消除单季资金排期波动，匹配 DCF 年化折现法则 |
| **静态截面 (Snapshot / Matrix)** | 敏感性矩阵、结构对比 | WACC × g 压力测试热力图、六维雷达自查图、SOTP 企业价值瀑布图 | 专注当下价格的容错空间与边界测算 |

## 五、 全流程投研工作流与子模块调用编排（Orchestration SOP）

当发起个股研究任务时，`investment-analyst` 协议按以下四阶段标准化推进：

```text
┌────────────────────────────────────────────────────────────────────────┐
│ 第一阶段：数据采集与事实底表净化 (investment-analyst)                   │
│ • 查验最新市价与完全稀释股本                                           │
│ • 提取 3~5 年 10-K 历史底表 + 最新 10-Q 资产负债与 TTM 现金流          │
│ • 穿透 IR 电话会实录，提取管理层口头指引与 Q&A 焦点                    │
└───────────────────────────────────┬────────────────────────────────────┘
                                    │ 交付标准数据底表
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│ 第二阶段：财报排雷与真实造血体检 (financial-forensics)                 │
│ • CFO / 净利润现金造血瀑布流（识别假繁荣）                            │
│ • 扒 SBC 股权稀释真实年化成本与净注销率                               │
│ • 营运资本与 CCC 穿透（区分占款飞轮还是垫资失血）                      │
│ • 严谨企业价值 EV Bridge 拆解                                          │
└───────────────────────────────────┬────────────────────────────────────┘
                                    │ 交付净化的核心营运资产与真实 FCF
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│ 第三阶段：预期投资学与估值引擎 (valuation-engine)                      │
│ • 运行反向 DCF 解算器：倒推当前市价隐含的 10 年 FCF 年化增速           │
│ • 市场隐含军令状 vs 历史基准对账，定位莫布森 2×2 预期差象限           │
│ • 垂直物种适配：SaaS (Rule of 40/FCF)、芯片周期正常化、航母企业 SOTP   │
│ • 输出 Bear / Base / Bull 三情景财务预测底表                          │

                                    │ 交付估值公允区间与期望盈亏比
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│ 第四阶段：买方决策、压力测试与备忘录 (investment-memo)                 │
│ • 双变量敏感性压力测试（测算不利环境下的底线价值）                     │
│ • 事前验尸（Pre-Mortem）反向推演 4 大潜在死因                          │
│ • 确立 3~4 项非价格前置证伪红线（触发即撤）                            │
│ • 运行基于 SEC 真实财务指标的六维量规自查打分                          │
│ • 输出标准 7 步买方投资备忘录与仓位分批建议                            │
└────────────────────────────────────────────────────────────────────────┘
```

## 六、 公司研究标准三份交付物规范（Standard 3-Document Deliverables）

在覆盖或深度复盘任何标的时，投研团队统一输出以下三份标准买方文档，形成从事实底表到风控决策的完整证据链：

### 1. `companies/<TICKER>/README.md` —— 【公司投研主档案与真实造血穿透底稿】
* **整合技能**：`investment-analyst` ＋ `financial-forensics`
* **核心内容**：
  * 核心投资论文与分部业务架构图谱；
  * 商业护城河与单位经济学分析；
  * 过去 3~5 年及最新 TTM 真实造血诊断（CFO ÷ 净利润瀑布流、SBC 股权稀释率与净回购核算、负 CCC 营运资本飞轮）；
  * 备考资本结构与严谨企业价值（EV Bridge）拆解底表。

### 2. `companies/<TICKER>/earnings/FYxxxx-Qx.md` —— 【季度业绩与电话会双轨复盘】
* **整合技能**：`investment-analyst`
* **核心内容**：
  * **法定信披硬事实轨（Form 8-K / 10-Q）**：分部营收同比/环比增速、GAAP 与 Non-GAAP 真实对账表、最新资产负债表与有息债务；
  * **电话会实录指引轨（Earnings Call Transcript）**：管理层开场口头定调、跨期指引更新、2~3 个华尔街分析师尖锐 Q&A 核心攻防还原；
  * **滚动 TTM 经营损益更新**：消除单季季节性波动，确保与经审计的 10-K 年报无缝对齐。

### 3. `companies/<TICKER>/research/investment-memo.md` —— 【买方投资备忘录与预期估值决议】
* **整合技能**：`valuation-engine` ＋ `investment-memo`
* **核心内容**：
  * **买方预期投资学（反向 DCF）**：运行解算器倒推当前市价隐含的 10 年 FCF 年化复合增速，对比 5 年历史实际增速与指引，定位莫布森 2×2 预期差象限（判定是否 Priced for Perfection）；
  * **垂直商业物种专属估值**：SaaS (Rule of 40/FCF)、芯片周期中枢正常化、多元化航母 SOTP 估值；
  * **正向三情景财务预测底表**：Bear (25%) / Base (50%) / Bull (25%) 测算公允价值与期望盈亏比（Risk/Reward）；
  * **双变量敏感性压力测试**：WACC × g 网格测算不利宏观环境下的防御底线价值；
  * **事前验尸（Pre-Mortem）**：买入前反向推演未来亏损 50% 的 4 大死因；
  * **非价格前置证伪红线**：订立 3~4 项可量化的基本面体检触发指标与撤退预案；
  * **客观六维量规自查得分**：基于 SEC 硬数据的客观雷达打分（及格线 45 分，单项 $\ge 6$ 分），输出目标仓位上限与击球区建仓执行节奏。
