## 五大通用排版语法规则

### 规则 1【加粗定界符（`**`）防崩与空距规范】
- **加粗标记内侧首尾严禁空格**：
  - 规范写法：`**(+) 短期有息借款 (ST Debt)**`、`**(=) 稀释股票总市值 (Market Cap)**`、`**纯文本**`；
  - ❌ 致命写法：`** text**`、`**text **`（根据 CommonMark/GFM 规范，起始 `**` 后紧跟空格会被判定为非法左定界符，原样暴露星号）。
- **列表小标题冒号内包**：统一写为 `* **小标题：** 正文`（冒号在粗体内，闭合 `**` 后留一个半角空格），严禁 `* **小标题**:` 或 `* **小标题**：正文`。
- **比较与正负算术符号外置**：粗体内只放纯数字与百分号/倍号，符号外置并留半角空格：
  - 规范写法：`≥ **4.0% ~ 5.0%**`、`< **1.0%**`、`＝ **10.95%** ≈ **11.0%** ；`、`+ **32.3%** ，`、`− **20.7%** ）`；
  - ❌ 致命写法：`**≥ 4.0%**`（符号导致定界符失效）、`**< 1.0%**`（`<` 会被误判为 HTML 标签导致文字被吞）。
- **闭合 `**` 紧邻全角标点时显式留半角空格**：加粗紧贴中文句号、分号、逗号或全角括号等标点时，必须在闭合星号与标点之间显式加一个半角空格（如 `**11.0%** 。`、`**8.5%** （`、`**24.4%** ）`），防止 mdnice (`marked.js`) 将全角标点视为普通字符而导致闭合定界符粘连失效。

### 规则 2【字符 `$` 职责解耦与行内代码块（`` `...` ``）边界】
- **行内代码块（`` `...` ``）仅用于两类需要语法隔离的字面量**：
  1. **保留 `$` 前缀的金融报价与点位**（如美股股价或行权区间 `` `$157.91` ``、`` `$150.00 ~ $160.00` ``），且外层绝对严禁加粗或嵌套 `**`；
  2. **计算机代码、命令与路径字面量**（如变量名、函数名、命令行与文件路径）。
- **常规文本禁止滥用行内代码块**：普通数值、四则运算推演、证券识别码、法规编号与常规中英文专有名词一律直接自然书写，不为普通文本套加反引号，避免微信后台渲染成杂乱的彩色底纹胶囊。
- **代码块之外严禁裸写货币 `$`**：通用货币金额按第一层规范采用纯中文单位（如 `7,450 亿美元`），代码块之外的所有 `$` 纯粹专职于 LaTeX 数学公式，彻底消除货币 `$` 与公式 `$` 跨段误配对。

### 规则 3【LaTeX 数学公式（`$$...$$` 与 `$...$`）排版与防崩边界】
- **块级公式与行内公式清晰分工**：
  - **独立居中块级公式（`$$ ... $$`）**：用于核心数学推导、方程组与多行演算，独占行渲染；
  - **标准行内公式（`$...$`）**：用于正文与表格内的数学符号、上下标及紧凑短表达式（如 `$P_0$`、`$r_{\text{index}, t}$`、`$\tau_t \to 0$`），墨滴会在复制到公众号时自动将两者转译为无损矢量 SVG 图文。
- **四条通用解析防崩边界**：
  1. **成对闭合与纯净符号**：同一非代码行（及同一表格单元格）内，代码块外的 `$` 必须严格成对出现；公式内汉字使用 `\text{...}` 包裹，不夹杂货币符号；
  2. **首尾无空、远离粗体**：`$...$` 内侧首尾严禁空格（写 `$P_0$` 而非 `$ P_0 $`）；`**...**` 与 `$...$` 既不互相嵌套，也不直接紧贴粘连（如写作 `**票息率** $c$ **属于合同**`）；
  3. **各级标题零公式**：`#` 至 `####` 各级标题行内只使用纯文本，不放置 `$...$`；
  4. **不等号与表格适应性**：公式内涉及 `<` / `>` 时优先改用 `\le` / `\ge`（或确保符号两侧留空格以免误触发 HTML 标签解析）；表格单元格内公式保持单行紧致（分式优先写 `$P_0 \times (c / 2)$` 代替 `\frac`），并严禁在表格公式中使用会破坏分列的裸竖线。
- **非公式正文的普通算术与比较采用标准 Unicode 字符**：
  - 算术与等号：`＝`、`＋`、`−`、`×`、`÷`、`≠`、`≈`
  - 比较与范围：`≥`、`≤`、`>`、`<`、`~`
  - 变动与微积分：`Δ`、`∑`、`→`、`±`

### 规则 4【信源引用上角标（`<sup>[n]</sup>`）】
- 墨滴不支持标准 Markdown 的 `[^1]` 脚注语法；正文中凡涉及引用文末信源列表时，统一采用 HTML 上角标形式（如 `<sup>[1]</sup>`、`<sup>[1][2]</sup>`），与文末信源清单编号一一对应。
- 普通汉字或右括号后直接紧贴 `<sup>[n]</sup>`（如 `2036 年 8 月 15 日<sup>[6]</sup>`）；若紧接在加粗闭合符 `**` 之后，必须在 `**` 与 `<sup>` 之间保留一个半角空格（如 `**3.830%** <sup>[5]</sup>`），避免 `**` 与 `<` 粘连干扰解析。

### 规则 5【微信公众平台与表格引擎硬红线】
- **引用块（`>`）单块 300 汉字上限**：单个 `<blockquote>`（`>`）引述内容绝对不得超过 300 汉字，超出在微信后台发布时会直接报错；`>` 仅用于简短导读、摘要或核心提示，绝不包裹长篇案例或正文段落。
- **禁用不支持的代码图**：微信后台不渲染 Mermaid 脚本，亦会在 ASCII 字符画边框（如 ````text ┌─── ````）中暴露行号；流程图、结构图与矩阵统一使用标准 Markdown 表格或高清配图。
- **表格单行平铺与跨端安全语法**：常规单维数据表一律保持单行平铺，**不人为插入 `<br>` 将“名称＋括号说明”或“数值＋备注”拆成两行**（微信表格默认横向滑动，人为拆行会无谓拉大行高并破坏同行对齐）；仅在双标的上下对照等确需同格分行的特定专栏场景下使用 `<br>`（严禁直接敲回车换行，且不在 `<br>` 前后多留空行）。严禁在 HTML `<td>` 上强制手写 `max-width`（粘贴进微信后台会导致原生编辑器闪退）。

## 通用排版语法速查表

| 排版场景 | ❌ 错误写法（渲染崩溃/视觉杂乱） | ✅ 规范写法（100% 稳定渲染） | 核心避坑机理 |
| :--- | :--- | :--- | :--- |
| **加粗内侧与冒号** | `** text**`、`* **门槛收益率**:` | `**text**`、`* **门槛收益率：** 正文` | 粗体内无空格；冒号移入粗体内且闭合后留半角空格 |
| **比较/符号与粗体** | `**≥ 4.0%**`、`**< 1.0%**` | `≥ **4.0%**`、`< **1.0%**` | 比较符与 `<` 移出粗体外，避开非法定界符与 HTML 误判 |
| **粗体紧贴全角标点** | `达到 **11.0%**。`、`**8.5%**（` | `达到 **11.0%** 。`、`**8.5%** （` | `**` 与中文全角句号、分号、逗号、括号间保留半角空格 |
| **带 `$` 报价点位** | 裸写 `$171.55` 或 `**$171.55**` | `` `$171.55` `` | 行内代码块隔离 `$` 且外层不加粗，不与公式 `$` 错配 |
| **普通数值与编码** | `` `10,000 × 4.625%` ``、`` `91282CRF0` `` | `10,000 × 4.625%`、`91282CRF0` | 普通数值、算式与识别码不套反引号，避免满屏彩色胶囊 |
| **行内与块级公式** | `**$P_0$**`、`$ P_0 $`、标题写 `$c$` | 块级 `$$...$$` ＋ 行内 `$r_{\text{index}, t}$` | 公式与粗体分离不紧贴、首尾无空格、标题纯文本 |
| **表格单行与内嵌公式** | 常规表加 `<br>` 拆括号、用 `\frac` 或竖线 | 常规表保持单行平铺；分式写 `$c / 2$` | 配合微信横滑压缩纵向行高，公式单行紧致且禁用竖线分列 |
| **信源引用上角标** | 正文用 `[^1]` 或 `**3.83%**<sup>[5]</sup>` | `2036 年<sup>[6]</sup>`、`**3.83%** <sup>[5]</sup>` | 兼容墨滴与公众号上角标，`</*` 之间留空格防粘连 |
| **引用块长度限制** | 用 `>` 包裹整段超过 300 字长分析 | 仅用 `>` 包裹 ≤ 300 字的简短摘要或提示 | 严守微信公众号单个 `blockquote` 300 汉字上限 |
| **架构与流程图表** | 使用 `mermaid` 或 ASCII 边框代码块 | 使用标准 Markdown 表格或高清配图 | 微信后台不支持 Mermaid 且 ASCII 框会暴露代码行号 |
