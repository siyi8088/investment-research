# 微信公众号与墨滴排版通用规则（WeChat Publishing Rules）

本规则适用于全工作区内所有面向微信公众号发布或使用墨滴 (mdnice) 排版的投研文章（包括 `articles/valuation_guide/`、`articles/industry_metrics_guide/` 及任何个股实战研报）。

---

## 核心排版执行铁律

1. **粗体定界符防崩（No Punctuation Collision）**：
   - **列表小标题**：统一写为 `* **小标题 (英文)：** 正文`（冒号包在加粗内部，粗体后紧跟半角空格），严禁写为 `* **小标题 (英文)**:` 或 `* **小标题 (英文)**：`。
   - **数学与比较符外置**：严禁 `**≥ 5%**` 或 `**< 1%**`。必须写为 `≥ **5%**`、`< **1%**`、`＝ **10.95%** ≈ **11.0%** ；`。
   - **标点粘连显式空格**：粗体紧贴句号、分号或中文左括号时，必须显式加半角空格，如 `**11.0%** 。`、`**20%** ；`、`**$2,050 亿** （其中...）`。
2. **数学公式与符号（Unicode Only）**：
   - 严禁使用 LaTeX 原生语法（`$...$` 或 `$$...$$`），微信公众号后台完全不支持。
   - 一律采用标准 Unicode 数学字符（`＝`、`÷`、`−`、`＋`、`×`、`±`、`∑`、`≥`、`≤`、`≈`、`Δ`、`→`）。
3. **表格紧凑对齐**：
   - 横向对比底表两家公司数据统一放在同一单元格内，用 `<br>` 紧凑换行对比，行间不留空行。
4. **引用块字数限制**：
   - 微信公众平台严格限制单个 `<blockquote>` 引用块不超过 300 汉字。正文长案例一律不用 `>` 包裹，`>` 仅用于文首一句话导读、走势图核心解读与文末买方心法。
