# 微信公众号与墨滴排版通用规则（WeChat Publishing Rules）

> **适用范围**：本工作区内所有面向微信公众号发布或使用墨滴 (mdnice) 渲染的投研专栏、行业手册与个股实战案例文章。  
> **核心定位**：全工作区常驻规则（Always-On）。所有下游文章生成必须 100% 遵守本规程，杜绝排版解析崩溃。

---

## 核心排版免死七大军规

### 军规 1【宏观体量一律采用标准纯中文金融单位】
- **严禁裸露美元符号混搭**：统一写作纯中文金融单位（如 `7,450 亿美元`、`10.20 亿美元`、`40 亿美元`、`1,650 亿人民币`）；
- ❌ **致命写法**：`$7,450 亿美元`、`$40 亿`、`$10.20 亿美元`；
- **底层避坑原理**：散落在正文中的裸露 `$` 极易被 `marked.js` 或微信编辑器判定为 LaTeX 行内公式的起始符，一旦在数段后遇到另一个 `$`，两段之间的全部中文会被误当成公式吞噬消失。

### 军规 2【每股股价与点位一律使用纯行内代码块包裹，外层绝对严禁加粗】
- **统一纯行内代码块**：统一写作纯反引号包裹（如 `` `$171.55` ``、`` `$227.00` ``、`` `$65.76` ``、`` `$165.00 ~ $175.00` ``）；
- ❌ **致命写法**：`**$171.55**`、`**`$171.55`**`、`**$65.76**`；
- **底层避坑原理**：`**` 与代码块定界符 ``` `` 紧贴时，解析器无法正确判定嵌套层级，极易导致粗体闭合失败，在手机端直接暴露原生星号。代码块本身自带醒目的底色与等宽字体，视觉效果远优于加粗。

### 军规 3【加粗语法 ( `**` ) 防崩与 Pangu 空距铁律】
- **列表小标题冒号内包**：统一写为 `* **小标题 (英文)：** 正文`（冒号在内，加粗后跟半角空格），严禁 `* **小标题 (英文)**:`；
- **数学与比较符号绝对外置**：加粗内部只留纯数字与百分号，符号外置并留半角空格：
  - 示例：`≥ **4.0% ~ 5.0%**`、`< **1.0%**`、`＝ **10.95%** ≈ **11.0%** ；`、`+ **32.3%** ，`、`- **20.7%** ）`；
  - ❌ 严禁：`**≥ 4.0%**`（符号导致定界符非法）、`**< 1.0%**`（`<` 会被误判为 HTML 标签导致文字被吞）；
- **标点粘连显式留半角空格**：加粗紧贴中文句号、分号、或全角括号时，必须在闭合星号与标点之间显式加半角空格：
  - 示例：`**11.0%** 。`、`**20%** ；`、`**8.5%** （`、`**24.4%** ）`。

### 军规 4【绝对禁用 LaTeX 原生公式语法，全面采用标准 Unicode】
- **微信后台完全不支持 LaTeX**：正文中严禁出现 `$...$` 或 `$$...$$` 原生数学公式语法，否则在微信后台直接显示源码；
- **全面采用标准 Unicode 数学字符**：
  - 算术与等号：`＝`、`＋`、`−`、`×`、`÷`、`≠`、`≈`
  - 比较与范围：`≥`、`≤`、`>`、`<`、`~`
  - 变动与微积分：`Δ`、`∑`、`→`、`±`

### 军规 5【表格跨端紧凑对齐与表头声明规范】
- **表头显式声明单位**：单位在表头统一定义（如 `单位：百万美元` 或表头声明 `(亿美元)`），单元格内部只放纯净数值或纯代码块点位，单元格内不散落 `$`；
- **跨标的/跨期对比在同一单元格内换行**：两家公司数据统一放入同一个单元格，使用 `<br>` 上下紧凑换行对比，严禁在两行之间多打空行；
- **禁止强制设置 `max-width`**：严禁在 `<td>` 标签上强制加 `max-width`，防止粘贴进微信公众号后台时原生编辑器闪退崩溃。

### 6. 军规 6【微信引用块 (Blockquote) 单块 300 汉字绝对红线】
- 微信公众平台严格限制：**单个 `<blockquote>`（即 `>`）引述内容绝对不得超过 300 汉字**，超出在发布时会直接报错；
- 正文中的长篇案例分析、推演段落绝不使用 `>` 包裹；
- `>` 仅用于：文首“一句话买方导读”（100 字内）、走势图“买方核心解读”（200 字内）、文末“买方终极心法”（100 字内）。

### 7. 军规 7【严禁 Mermaid JS 与 ASCII 字符边框代码块】
- 微信公众号后台不支持 Mermaid 图表脚本，会直接暴露源码；
- 严禁在公众号发布文章中使用 ````text ┌─── ```` 这类 ASCII 边框代码块；
- 矩阵和架构一律用标准 Markdown 表格排版，自查表一律用“步骤卡片流 ＋ 🟢/🟡/🔴 指示灯 ＋ 行内代码块反引号”进行高保真排版。
