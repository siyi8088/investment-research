# 微信公众号与墨滴排版通用规则（WeChat Publishing Rules）

> **适用范围**：本工作区内所有面向微信公众号发布或使用墨滴 (mdnice) 渲染的投研专栏、行业手册与个股实战案例文章。  
> **核心定位**：全工作区常驻发布防御规程（Always-On Channel Defense）。本文件为解决微信公众号后台及墨滴 (`marked.js`) 渲染引擎特定缺陷的**第二层专属规则**，必须在满足 **第一层：系统级通用数据素养（`.agents/rules/investment-rules.md`）** 前提下严格执行。

## 核心排版免死七大军规

### 军规 1【加粗语法 ( `**` ) 防崩与 Pangu 空距铁律】
- **加粗标记内侧绝对严禁空格（No Whitespace Inside `**`）**：
  - 规范写法：`**(+) 短期有息借款 (ST Debt)**`、`**(=) 稀释股票总市值 (Market Cap)**`、`**纯文本**`；
  - ❌ 致命写法：`** (+) 短期有息借款**`、`** text**`、`**text **`；
  - **底层避坑原理**：根据 CommonMark 与 GFM 规范，加粗起始符号 `**` 后面紧跟空格时会被判定为非法左定界符，解析器会直接放弃加粗解析，原样暴露出原生星号 `**`；
- **列表小标题冒号内包**：统一写为 `* **小标题 (英文)：** 正文`（冒号在内，加粗后跟半角空格），严禁 `* **小标题 (英文)**:`；
- **数学与比较符号绝对外置**：加粗内部只留纯数字与百分号，符号外置并留半角空格：
  - 规范写法：`≥ **4.0% ~ 5.0%**`、`< **1.0%**`、`＝ **10.95%** ≈ **11.0%** ；`、`+ **32.3%** ，`、`- **20.7%** ）`；
  - ❌ 致命写法：`**≥ 4.0%**`（符号导致定界符非法）、`**< 1.0%**`（`<` 会被误判为 HTML 标签导致文字被吞）；
- **标点粘连显式留半角空格**：加粗紧贴中文句号、分号、或全角括号时，必须在闭合星号与标点之间显式加半角空格：
  - 规范写法：`**11.0%** 。`、`**20%** ；`、`**8.5%** （`、`**24.4%** ）`。

### 军规 2【宏观纯中文与股价代码块防御机理】
*(通用金融标准见 `investment-rules.md`，此处阐述微信渠道防御机理)*
- **宏观与金融体量一律采用标准纯中文金融单位**：
  - 规范写法：`7,450 亿美元`、`10.20 亿美元`、`40 亿美元`、`1,650 亿人民币`；
  - ❌ 致命写法：`$7,450 亿美元`、`$40 亿`、`$10.20 亿美元`；
  - **底层避坑原理**：散落在正文中的裸露 `$` 极易被 `marked.js` 或微信编辑器判定为 LaTeX 行内公式的起始符，一旦在数段后遇到另一个 `$`，两段之间的全部中文会被误当成公式吞噬消失。
- **每股股价与点位一律使用纯行内代码块包裹，外层绝对严禁加粗**：
  - 规范写法：`$157.91`、`$227.00`、`$65.76`、`$165.00 ~ $175.00`；
  - ❌ 致命写法：裸露加粗 `**$157.91**`、在代码块外层嵌套加粗（如 `**` + `` `$157.91` `` + `**`）；
  - **底层避坑原理**：`**` 与代码块定界符紧贴时，解析器无法正确判定嵌套层级，极易导致粗体闭合失败，在手机端直接暴露原生星号。代码块本身自带醒目的底色与等宽字体，视觉效果远优于加粗。

### 军规 3【数学公式与 LaTeX 排版铁律（墨滴矢量转译）】
- **推荐使用【独立居中块级公式】（Display Math: `$$ ... $$`）**：
  - 核心数学推导、IRR 年化收益测算、反向 DCF、期望盈亏比等，一律采用标准的独占行块级公式 `$$ ... $$` 呈现；墨滴 (mdnice) 在一键复制到微信公众平台时会自动将其转译为无损矢量 SVG 图文，既消除了黑色终端代码块的突兀感，又具备顶级买方研究的严谨排版美感；
  - **公式纯数值与干净符号原则**：公式内部只使用纯净数字（如 `76.00` 而非带 `\$` 的货币字符），汉字使用 `\text{...}` 包裹，避免宏包生僻指令；
- **绝对严禁正文行内使用单个美元符号（Inline Math: `$...$`）**：
  - 正文行内严禁出现 `$...$` 公式语法，彻底杜绝单 `$` 与正文中的其他符号发生灾难性“跨段配对吞噬”；
- **正文普通文本算术全面采用标准 Unicode 字符**：
  - 算术与等号：`＝`、`＋`、`−`、`×`、`÷`、`≠`、`≈`
  - 比较与范围：`≥`、`≤`、`>`、`<`、`~`
  - 变动与微积分：`Δ`、`∑`、`→`、`±`

### 军规 4【表格跨端自适应与纯净度规范】
- **严格遵循第一层数据纯净度铁律**：
  - 表格单位单一定义（要么在表头上方统一标注 `单位：百万美元（特殊标注除外）`，要么在不同单位的多列列头中注明 `(百万美元)`）；
  - 单元格内部 100% 只放纯净数值或纯代码块点位，**绝对严禁附加散落的 `M`、`B`、`$` 或 `百万`**，消灭单位冗余与解析风险；
- **跨标的/跨期对比在同一单元格内换行**：
  - 两家公司或两个基准数据统一放入同一个单元格，使用 `<br>` 上下紧凑换行对比，严禁在两行之间多打空行；
- **禁止强制设置 `max-width`**：
  - 严禁在 `<td>` 标签上强制加 `max-width`，防止粘贴进微信公众号后台时原生编辑器闪退崩溃；
- **墨滴消除表格多余行高通用 CSS 配置**（可注入墨滴自定义 CSS）：
  ```css
  table td {
    line-height: 1.25 !important;
    vertical-align: middle !important;
  }
  table td br {
    display: inline !important;
    margin: 0 !important;
    padding: 0 !important;
  }
  ```

### 军规 5【微信引用块 (Blockquote) 单块 300 汉字绝对红线】
- 微信公众平台严格限制：**单个 `<blockquote>`（即 `>`）引述内容绝对不得超过 300 汉字**，超出在发布时会直接报错；
- 正文中的长篇案例分析、推演段落绝不使用 `>` 包裹；
- `>` 仅用于：文首“一句话买方导读”（100 字内）、走势图“买方核心解读”（200 字内）、文末“买方终极心法”（100 字内）。

### 军规 6【严禁 Mermaid JS 与 ASCII 字符边框代码块】
- 微信公众号后台不支持 Mermaid 图表脚本，会直接暴露源码；
- 严禁在公众号发布文章中使用 ````text ┌─── ```` 这类 ASCII 边框代码块；
- 矩阵和架构一律用标准 Markdown 表格排版，自查表一律用“步骤卡片流 ＋ 🟢/🟡/🔴 指示灯 ＋ 行内代码块反引号”进行高保真排版。

### 军规 7【读者视角纯净性与静默附注铁律】
- **文稿面向读者交付，只呈现最终客观事实与测算结论，严禁包含任何内部会话讨论过程、审核指令自白或情绪化强调；所有必要说明与对账细节一律使用静默附注。**
